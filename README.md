# ポイント管理Webアプリ

HTML・CSS・JavaScriptで制作したポイント管理Webアプリです。

実生活での子どものお小遣い管理をきっかけに開発を始めました。お手伝いや学習などの行動にポイントを付け、ポイントの残高や履歴、目標を管理できます。

## 概要

子どものお手伝いや学習に対してポイントを付与し、一定ポイントに達したときのお小遣い支給を管理するために制作しました。

当初は紙のポイントカードを使っていましたが、カードをなくしやすいことや、現在のポイント数を把握しづらいこと、家庭内で運用ルールが変わることが課題でした。これらを解決するため、ポイントや履歴をブラウザ上で管理できるアプリを作りました。

開発を進める中で、利用者ごとに項目や目標を設定できる形へ機能を広げています。

## 主な機能

### 利用者管理

- 利用者の追加・編集・削除
- 利用者の切り替え

### 項目管理

- ポイント付与に使う項目の追加・編集・削除
- 項目ごとのポイント設定
- 項目名の重複チェック

### ポイント管理

- 項目に応じたポイントの加算
- ポイントの支給と残高からの減算
- マイナス残高の許可設定
- 現在ポイントと累計ポイントの表示
- 現在ポイントのリセット

現在ポイントをリセットしても、累計ポイントは保持する仕組みです。

### 履歴

- 利用者ごとのポイント履歴
- 直近5件の表示
- 全履歴の表示

### 目標

- 利用者ごとの個人目標
- 利用者全体の共有目標
- 進捗バーによる達成状況の表示
- 目標機能のON/OFF
- 個人目標・共有目標の切り替え

共有目標では、同じブラウザ内の利用者の現在ポイントを合算して進捗を表示します。

### 設定・データ保存

- 削除確認のON/OFF
- アプリデータの初期化
- LocalStorageへのデータ保存

データは利用しているブラウザ内で管理されます。現時点では、ログイン機能や端末間のデータ同期には対応していません。ブラウザの保存データを削除すると、アプリのデータも失われる可能性があります。

## 実装で工夫した点

### 利用者ごとのポイントデータ管理

利用者ごとに現在ポイント、累計ポイント、目標、履歴を管理しています。利用者を切り替えると、選択した利用者の情報を画面に表示します。

### 現在ポイントと累計ポイントの管理

ポイントの加算時に現在ポイントと累計ポイントを更新し、支給時は現在ポイントから差し引く仕組みにしました。現在ポイントをリセットしても累計ポイントは保持されるため、残高と累計を分けて確認できます。

### 目標達成状況の可視化

個人目標と共有目標の進捗を、ポイント数・残りポイント・進捗バーで表示します。目標までの状況を把握しやすくすることを意識しました。

### 設定による使い分け

マイナス残高の許可、削除確認、目標機能の利用などを設定画面から切り替えられるようにし、家庭ごとの運用方法に合わせて使える構成にしました。

## 苦労した点

当初は家庭内での利用を想定していましたが、利用者ごとにポイントや目標を管理できるようにする過程で、データ構造や状態管理の見直しが必要になりました。

利用者、項目、ポイント、目標、履歴の情報を整理し、機能を追加したときにどのデータへ影響するかを考えながら開発を進めています。この経験から、機能追加だけでなく、データの持ち方や状態の管理方法を見直すことの重要性を学びました。
